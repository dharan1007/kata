API agent contracts

Discovers standards-declared OpenAPI and creates local agent contracts. Execution is available only for a freshly re-discovered same-origin operation after an exact request preview and a second explicit action. KATA never asks you to paste cookies, API keys, or bearer tokens.

MCP endpoint

Same-origin HTTPS only, except loopback HTTP for local development. Discovery never sends cookies or tokens. Public modern MCP tools can be listed and invoked only after a fresh exact preview and explicit approval.
