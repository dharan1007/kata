KATA

Interop Inspector

Inspect only the tab you explicitly authorize. Page content and credentials are not sent to KATA.

API agent contracts

Discovers standards-declared OpenAPI and creates local agent contracts. Execution is available only for a freshly re-discovered same-origin operation after an exact request preview and a second explicit action.

MCP endpoint

Same-origin HTTPS only, except loopback HTTP for local development. Discovery never sends cookies or tokens. Public modern MCP tools can be listed and invoked only after a fresh exact preview and explicit approval.

MCP discovery

Server requires explicit input

KATA never auto-answers this round. Review the server request, provide only the current round responses, preview again, then explicitly approve the resumed call.


          
          
          
          

          
          
        

        

          
Long-running MCP task

          
Task state stays local. KATA never polls in the background, never auto-submits task input, and never treats a cancellation request as proof the server has already stopped work.

          

          
          

            
            
            
            

            
            
          

          
          

          
          
        

      

    

    

      
Session authorization

      
Secrets stay in chrome.storage.session for this browser session only. They are not model arguments, are not sent to KATA, are not persisted to disk/sync, and cannot be revealed from this UI after saving.

      
      
      
      
      
      
      
      
      
      
      
      
      
      
      
      
      
      
Protected API

      
Uses the currently selected compiled OpenAPI operation and its arguments. Brokered secrets are resolved only in the extension service worker after a fresh preview.

      
      

      
      
      

      
Protected MCP

      
Select a Bearer session credential. Protected modern MCP remains same-origin, redirects stay manual, ambient browser credentials remain omitted, and each execution is freshly previewed.

      
      
      

      
      
      

      
Session tasks

      
Task handles remain in session storage. Closing the popup no longer loses an active task, but KATA still never polls or resumes it automatically.
